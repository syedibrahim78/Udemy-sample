Udemy Website Sample
Project Overview:
            This project is a simple static website created to resemble a Udemy-like online learning platform. It showcases the use of HTML and CSS for creating the structure and styling of the site. The project includes various components such as:

Homepage with featured courses Course details page Responsive layout for different devices Features

Homepage:
      A clean and modern layout featuring popular courses, a search bar, and various category sections.
Course Page: A detailed view of individual courses, including a description, course instructor, and related courses.
Responsive Design: The site adapts to different screen sizes using media queries to provide an optimal experience on desktops, tablets, and smartphones.
Tech Stack
HTML5: For creating the structure of the website.
CSS3: For styling the website, including layout and design, using Flexbox, Grid, and custom CSS rules.
Responsive Design: Media queries for different screen sizes.
